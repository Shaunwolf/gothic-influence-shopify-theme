## 🚀 Quick Install (5 Minutes)

### Step-by-Step:

1. Open Shopify Admin: https://admin.shopify.com/store/gothic-influence
2. Go to **Online Store → Themes**
3. Find **Horizon** theme → Click **Customize**
4. Click **Theme settings** (bottom left gear icon)
5. Find **Additional CSS** section
6. Copy entire contents of `/data/workspace/shopify_theme.css`
7. Paste into CSS field
8. Click **Save**
9. View store: https://gothic-influence.myshopify.com

**Done!** Your theme is live.

## 🔧 Customization

### Change Primary Green
Find line in CSS:
```css
--color-gothic-green: #2d6a40
```
Change to your preferred green.

### Change Primary Gold
Find line in CSS:
```css
--color-copper-gold: #c9a961
```
Change to your preferred accent color.

### Adjust Text Color
Find line in CSS:
```css
--color-text-primary: #f5f5f5
```
Change for different text brightness.

**Save changes → Reupload to Shopify → Done!**

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| CSS didn't apply | Clear cache (Ctrl+Shift+Delete), refresh (Ctrl+F5) |
| Colors look wrong | Verify full CSS was copied, no text cut off |
| Layout broken | Check all CSS was pasted, no special characters |
| Mobile looks bad | Refresh page, test in Chrome DevTools |
| Links not styled | Verify CSS file is properly linked |
