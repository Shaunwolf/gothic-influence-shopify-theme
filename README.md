# Gothic Influence - Shopify Theme

A dark, elegant, and sophisticated Shopify theme featuring:

✨ **Dark Color Palette**
- Light blacks (#0d0d0d)
- Dark grays (#1a1a1a, #2a2a2a, #3a3a3a)
- Gothic greens (#2d6a40)
- Copper gold accents (#c9a961)

✨ **Professional Design**
- Responsive layout (mobile, tablet, desktop)
- Smooth animations and hover effects
- Beautiful typography (Playfair Display + Poppins)
- Header with animated navigation
- Product grid with glow effects
- Professional footer

## Installation

### Option 1: Shopify GitHub Import (Recommended)
1. Go to Shopify Admin → Online Store → Themes
2. Click "Add theme"
3. Select "Import from GitHub"
4. Connect your GitHub account
5. Select `ShaunWolf/gothic-influence-shopify-theme`
6. Click Import

### Option 2: Manual Upload
1. Download this repository
2. Go to Shopify Theme Code Editor
3. Upload the files
4. Customize as needed

## Color Customization

Edit `assets/custom-gothic.css` to customize colors:

```css
--color-dark-black: #0d0d0d
--color-gothic-green: #2d6a40
--color-copper-gold: #c9a961
--color-text-primary: #f5f5f5
```

## Files

- `assets/custom-gothic.css` - Main theme stylesheet
